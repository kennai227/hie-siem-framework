08 Architecture Decisions
ADR-001
Cross-Cloud Strategy
Ontario hospitals use Azure/M365 (Ministry agreements). Cloud-native EHR APIs run on AWS. Single-cloud SIEM creates blind spots.
→ AWS + Azure with VPN tunnel and unified ECS schema
ADR-002
Wazuh over Splunk
HIE environments have high log volumes and budget constraints. Splunk charges ~$180K/year at 50GB/day ingestion.
→ Wazuh 4.7 + OpenSearch (Apache 2.0) — $0 licensing
ADR-003
ECS Log Normalization
AWS VPC and Azure NSG logs have different schemas. Writing cloud-specific rules doubles maintenance burden significantly.
→ All logs normalized to ECS 8.x via Logstash pre-index
ADR-004
7-Year WORM Storage
HIPAA requires 6yr audit log retention. S3 COMPLIANCE mode cannot be overridden even by AWS root — stronger than GOVERNANCE.
→ S3 Object Lock COMPLIANCE + Azure Immutable Blob ZRS
ADR-005
Isolation Forest for ML
Rule-based network detection generates excessive false positives during HL7 batch transfers. Needed ML baseline approach.
→ sklearn IsolationForest, contamination=0.01, 30-day train
